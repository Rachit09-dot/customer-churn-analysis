📊 Customer Churn Analysis & Prediction
🚀 Project Overview
This project focuses on analyzing customer behavior and predicting customer churn using data analytics and machine learning techniques.

Customer churn refers to when customers stop using a company's service. Identifying such customers in advance helps businesses take preventive actions.

🎯 Objectives
Analyze customer data to identify churn patterns
Perform Exploratory Data Analysis (EDA)
Build a predictive model using Logistic Regression
Extract meaningful business insights

💡 Key Insights
Customers with low tenure are more likely to churn
High support calls indicate dissatisfaction
Low usage frequency leads to higher churn
Customers with lower total spend churn more
🤖 Machine Learning Model
Model Used: Logistic Regression
Accuracy Achieved: 87%
Balanced precision and recall
⚙️ Model Improvements
Applied feature scaling using StandardScaler
Increased iterations to resolve convergence warning
Removed irrelevant features like CustomerID

The model successfully predicts customer churn and can help businesses:

Identify at-risk customers

Increase customer satisfaction
